How the radar works

A protocol “records no token” when the snapshot records none for it — that is DefiLlama’s record, not proof it has none. The implied value is this entry’s own claim: what a launch would be worth if the protocol’s record stayed as it is. It is not a prediction that a token will be issued, or when. Farm plans are a starting point, not financial advice; every step carries its own risk note — read it before you put money in.
