Yield Radar ranks 190 pre-token DeFi yield protocols by implied launch value using a transparent fee-revenue-quality formula (TVL × family fee multiple × growth × maturity × chain breadth), with a 5-step farm plan per protocol carrying an estimated cost and a risk note on every step, plus a comparables table of 24 already-live tokens.

## Run it

```sh
node main.ts
```
